# 简历项目描述（Java 后端方向）

以下只描述当前实际实现。请先按演示文档运行并理解源码，再改成自己的表述。项目是借助 AI 协作完善的个人学习项目，不应写成企业工作经历、独立研发经历或商业上线成果。

## 可直接修改的项目段落

**栖居租赁管理系统｜个人学习项目**

技术栈：Java 11、Spring MVC、MyBatis、MySQL、Redis、JUnit 5、Maven、Docker Compose、Vue 3。

- 在原 SSM Demo 上完善房源、租客、合同、月账单、分次收款与退租流程，使用 DTO 校验、统一异常响应和操作审计维护接口边界。
- 使用 Spring 事务、MySQL 行锁和唯一索引约束重复出租；基于业务幂等号与账单锁实现重复收款去重，处理部分收款、超额收款和状态冲突。
- 基于 Redis 与 Lua 管理单账号会话、空闲续期和撤销，实现角色权限校验；采用 PBKDF2 存储密码，避免响应暴露密码。
- 建立 Maven 构建、Docker Compose 启停与隔离测试流程，18 项单元测试和 12 项真实接口测试通过，覆盖并发签约、幂等收款、越权访问、禁用会话与退租结算。

如果简历空间有限，保留第一、第二、第四条即可。熟悉程度不足的内容写“实践/了解”，不要仅因代码存在就写“精通”。
